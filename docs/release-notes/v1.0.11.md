## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **Caratteri di controllo nei file INI**: un valore con un a capo (CR/LF) non può più finire nei file di configurazione, dove avrebbe potuto iniettare righe o chiavi nella sezione successiva. Vale per `server_cfg.ini`, `entry_list.ini`, `welcome.txt`, `race.ini` e `assists.ini`; il salvataggio si ferma e mostra un messaggio invece di scrivere il file.
- **Preset**: il contenimento nella cartella `presets/` usa un unico controllo canonico, sia per il caricamento sia per l'import da Content Manager. I preset importati non possono contenere link simbolici o junction che puntano fuori.
- **Distribuzione**: la pipeline di release esegue anche `npm audit` e `cargo audit`, e le azioni GitHub sono pinnate al commit esatto anziché a un tag mobile.

### Compatibilità

- Nessun cambiamento visibile nell'interfaccia, nessuna modifica a inviti, protocollo o formato dei file `.ini`.
- Aggiornamento consigliato: la 1.0.10 funziona, ma questa versione chiude un'iniezione possibile nei file INI.
- I launcher 1.0.2–1.0.10 sono compatibili.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **Control characters in INI files**: a value containing a newline (CR/LF) can no longer reach the configuration files, where it could have injected lines or keys into the next section. This covers `server_cfg.ini`, `entry_list.ini`, `welcome.txt`, `race.ini` and `assists.ini`; the save stops with a message instead of writing the file.
- **Presets**: confinement to the `presets/` folder now uses a single canonical check, for both loading and importing from Content Manager. Imported presets cannot contain symbolic links or junctions pointing outside.
- **Distribution**: the release pipeline also runs `npm audit` and `cargo audit`, and GitHub actions are pinned to exact commits instead of moving tags.

### Compatibility

- No visible interface change, and no change to invites, the protocol or the `.ini` file format.
- Recommended update: 1.0.10 works, but this version closes a possible injection in the INI files.
- 1.0.2–1.0.10 launchers are compatible.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
