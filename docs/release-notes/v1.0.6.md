## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **Pagina Slot**: se un amico prenota mentre stai modificando gli slot, le tue modifiche non vengono più sostituite. Compare un avviso con "Scarta e ricarica".
- **Lettura e salvataggio degli slot** sono atomici rispetto alle prenotazioni: niente liste lette a metà.
- **Prenotazioni**: la configurazione (`CARS`, `MAX_CLIENTS`, pista) viene letta e validata sotto lo stesso lock della scrittura, quindi una modifica appena salvata non viene aggirata.
- **Preset**: anche il salvataggio usa il lock e cattura i tre file nello stesso istante.
- **Lock delle impostazioni**: su Windows è un mutex nominato, con esclusione reale tra Manager e Launcher e rilascio automatico se un processo termina di colpo.

### Compatibilità

- Nessuna modifica a link d'invito, protocollo o file `.ini`.
- I launcher 1.0.0–1.0.5 continuano a funzionare.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **Slots page**: if a friend books while you are editing slots, your changes are no longer replaced. A banner offers "Discard and reload".
- **Reading and saving slots** are atomic with respect to bookings: no half-read lists.
- **Bookings**: the configuration (`CARS`, `MAX_CLIENTS`, track) is read and validated under the same lock as the write, so a just-saved change cannot be bypassed.
- **Presets**: saving also takes the lock and captures the three files at the same instant.
- **Settings lock**: on Windows it is a named mutex, with real exclusion between Manager and Launcher and automatic release if a process dies.

### Compatibility

- No changes to invite links, the protocol or `.ini` files.
- 1.0.0–1.0.5 launchers keep working.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
