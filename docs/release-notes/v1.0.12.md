## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **Caricamento dei preset**: i tre file di configurazione vengono copiati solo se sono file regolari. Un collegamento simbolico o una junction con il nome di `server_cfg.ini`, `entry_list.ini` o `welcome.txt` viene rifiutato, quindi un preset non può portare dentro `cfg/` il contenuto di un file che sta altrove.
- **Messaggio di benvenuto**: `welcome.txt` accetta le interruzioni di riga e le tabulazioni, ma rifiuta gli altri caratteri di controllo.
- **Audit delle dipendenze**: `npm audit` ora controlla anche le dipendenze di sviluppo, in CI e in fase di release.

### Compatibilità

- Nessun cambiamento visibile nell'interfaccia e nessuna modifica al formato dei file.
- I preset esistenti continuano a funzionare: vengono rifiutati solo quelli che contengono collegamenti al posto dei file.
- I launcher 1.0.2–1.0.11 sono compatibili.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **Loading presets**: the three configuration files are copied only if they are regular files. A symbolic link or a junction named `server_cfg.ini`, `entry_list.ini` or `welcome.txt` is refused, so a preset cannot pull the content of a file living elsewhere into `cfg/`.
- **Welcome message**: `welcome.txt` accepts line breaks and tabs, but refuses the other control characters.
- **Dependency audit**: `npm audit` now also covers development dependencies, in CI and during the release.

### Compatibility

- No visible interface change and no change to the file format.
- Existing presets keep working: only those containing links instead of files are refused.
- 1.0.2–1.0.11 launchers are compatible.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
