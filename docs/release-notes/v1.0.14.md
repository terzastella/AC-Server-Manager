# AC Server Control — v1.0.14

Ripristino dei preset più robusto: niente file cancellati e nessun errore nascosto.

## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **Rollback dei preset**: se un file della configurazione attuale esiste ma non è leggibile (permessi, contenuto non UTF-8), il caricamento del preset si ferma **prima** di scrivere. Prima quel file veniva considerato "assente" e in fase di ripristino poteva essere cancellato.
- **Ripristino dichiarato per quello che è**: se una scrittura fallisce e il ripristino non riesce del tutto, l'errore lo dice e rimanda ai backup in `backups/`, invece di far credere che sia andato tutto bene.

### Compatibilità

- Nessun cambiamento visibile nell'interfaccia e nessuna modifica al formato dei file.
- I preset esistenti continuano a funzionare.
- I launcher 1.0.2–1.0.13 sono compatibili.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **Preset rollback**: if a file of the current configuration exists but cannot be read (permissions, non-UTF-8 content), loading the preset stops **before** writing. Previously that file was treated as "absent" and could be deleted during the restore.
- **Restore reported honestly**: if a write fails and the rollback does not fully succeed, the error says so and points to the backups in `backups/`, instead of pretending everything went fine.

### Compatibility

- No visible interface change and no change to the file format.
- Existing presets keep working.
- 1.0.2–1.0.13 launchers are compatible.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
