## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **API solo su questo PC per impostazione predefinita**: il bind predefinito passa da `0.0.0.0` a `127.0.0.1`. Per far entrare gli amici si sceglie l'indirizzo della VPN nella pagina Invito (serve riavviare l'app). Se avevi già salvato un indirizzo, resta quello.
- **Token solo nell'header `Authorization: Bearer`**: rimosso il fallback sul parametro `token` della query e sul campo `token` del corpo JSON. Erano vie legacy che finivano nei log dei proxy e nella cronologia.
- **Slot senza limite**: con `MAX_CLIENTS` mancante o non valido il tetto veniva ignorato e le prenotazioni potevano aggiungere slot all'infinito. Ora la richiesta viene rifiutata con un messaggio chiaro.

### Compatibilità

- I launcher **1.0.2–1.0.8** continuano a funzionare: usano già il token nell'header.
- I launcher **1.0.0–1.0.1** non sono più compatibili (mandavano il token nell'URL): aggiorna anche il launcher degli amici.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **API on this PC only by default**: the default bind changed from `0.0.0.0` to `127.0.0.1`. To let friends in, pick the VPN address in the Invite page (app restart required). An address you already saved stays as it is.
- **Token only in the `Authorization: Bearer` header**: the fallback on the `token` query parameter and the `token` body field is gone. Those legacy paths ended up in proxy logs and browser history.
- **Unbounded slots**: with a missing or invalid `MAX_CLIENTS` the cap was ignored and bookings could add slots forever. The request is now refused with a clear message.

### Compatibility

- **1.0.2–1.0.8** launchers keep working: they already send the token in the header.
- **1.0.0–1.0.1** launchers are no longer compatible (they carried the token in the URL): update your friends' launcher too.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
