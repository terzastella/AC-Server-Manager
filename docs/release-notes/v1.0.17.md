# AC Server Control — v1.0.17

Hardening su launcher e profili: niente GUID fuori intervallo, niente junction adottate dall'indice.

## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,4 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **SteamID64**: l'account id letto da Steam viene accettato solo entro i 32 bit e sommato alla base Steam con aritmetica controllata. Un valore anomalo ferma il join con un messaggio, invece di generare un GUID che il server avrebbe rifiutato.
- **Profili**: oltre alla ricostruzione dell'indice, ora vengono controllati anche i profili già elencati in `index.json`: se la loro cartella è diventata una junction o un link, o se lo è `cfg/`, il profilo viene scartato.
- **`race.ini`**: il backup viene scritto solo a configurazione validata, subito prima della scrittura atomica. Un join annullato prima non tocca la copia.
- **Scrittura atomica**: il file temporaneo viene sempre rimosso anche quando la scrittura fallisce; prima poteva restare un `.tmp` sul disco.

### Compatibilità

- Nessun cambiamento visibile nell'interfaccia e nessuna modifica al formato dei file.
- I launcher 1.0.2–1.0.16 sono compatibili.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.4 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **SteamID64**: the account id read from Steam is accepted only within 32 bits and added to the Steam base with checked arithmetic. An unexpected value stops the join with a message instead of producing a GUID the server would refuse.
- **Profiles**: besides the index rebuild, profiles already listed in `index.json` are validated too: if their folder became a junction or a link, or if `cfg/` did, the profile is dropped.
- **`race.ini`**: the backup is written only after the configuration is validated, right before the atomic write. A join cancelled earlier no longer updates the copy.
- **Atomic write**: the temporary file is always removed, even when the write fails; previously a stray `.tmp` could be left behind.

### Compatibility

- No visible interface change and no change to the file format.
- 1.0.2–1.0.16 launchers are compatible.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
