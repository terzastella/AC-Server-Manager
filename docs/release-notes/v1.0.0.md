# AC Server Control — v1.0.0

Pannello portable per il server dedicato di Assetto Corsa, con il launcher che porta gli amici in partita con un solo clic.

[![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-0078D6?style=flat-square)](https://github.com/terzastella/AC-Server-Manager) [![i18n](https://img.shields.io/badge/i18n-IT%20%7C%20EN-ff5a1f?style=flat-square)](https://github.com/terzastella/AC-Server-Manager) [![License](https://img.shields.io/badge/license-MIT-97ca00?style=flat-square)](https://github.com/terzastella/AC-Server-Manager/blob/main/LICENSE)

## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop del server, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa c'è dentro

- Avvio, stop e riavvio del server con **log live** e stato in tempo reale
- Editor di `server_cfg.ini` e `entry_list.ini` **senza perdere commenti e ordine**, con la spiegazione di ogni campo
- Slot con auto, livrea e pilota; prenotazione "soft" per nome
- Browser contenuti con anteprime e copia dal gioco al server
- Content Manager letto in **sola lettura** (nessuna scrittura su `Values.data`)
- Rete: IP rilevati, link `acmanager://`, QR code, controllo porte, regole firewall
- Invito con grafica personalizzata, token e API di prenotazione
- Profili multipli che condividono gli stessi contenuti
- Preset, backup automatici, log delle sessioni precedenti
- Interfaccia **italiano / inglese**, si cambia al volo

### Avvio rapido

1. Metti i due `.exe` nella cartella del server, accanto a `acServer.exe`
2. Apri `ACServerControl.exe`: al primo avvio rileva la cartella e crea `settings.json`
3. Configura server, slot e invito dalle pagine del pannello
4. **Avvia server**, poi copia il link d'invito dalla pagina *Invito*
5. Gli amici aprono il link con `ACLauncher.exe` e cliccano **Entra**

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot
- Per giocare in rete: Hamachi, Radmin VPN, ZeroTier, Tailscale o port forwarding

### Note

- Le prenotazioni valgono dal **successivo avvio** del server (AC legge `entry_list.ini` all'avvio)
- Il join diretto scrive `race.ini` (`[REMOTE]`) e avvia `acs.exe`: **Content Manager non serve**
- L'API delle prenotazioni va tenuta raggiungibile solo dai tuoi amici (dentro la VPN)

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What's inside

- Start, stop and restart the server with **live logs** and real-time status
- `server_cfg.ini` and `entry_list.ini` editor that **keeps comments and order**, with an explanation for every field
- Slots with car, skin and driver; soft booking by driver name
- Content browser with previews and copy from the game to the server
- Content Manager read **read-only** (never writes `Values.data`)
- Network: detected IPs, `acmanager://` links, QR code, port checks, firewall rules
- Branded invite page, token and booking API
- Multiple server profiles sharing the same content
- Presets, automatic backups, logs of previous sessions
- **Italian / English** interface, switchable on the fly

### Quick start

1. Drop both `.exe` files next to `acServer.exe`
2. Run `ACServerControl.exe`: it detects the folder and creates `settings.json`
3. Configure server, slots and invite in the panel
4. Hit **Start server**, then copy the invite link from the *Invite* page
5. Friends open the link with `ACLauncher.exe` and click **Enter**

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
- Networking: Hamachi, Radmin VPN, ZeroTier, Tailscale or port forwarding

### Notes

- Bookings apply from the **next server start** (AC reads `entry_list.ini` at startup)
- Direct join writes `race.ini` (`[REMOTE]`) and starts `acs.exe`: **no Content Manager needed**
- Keep the booking API reachable by your friends only (inside the VPN)
