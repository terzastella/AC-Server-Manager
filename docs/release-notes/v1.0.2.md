## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **`entry_list.ini`**: solo un file assente vale come vuoto. Se il file è bloccato o illeggibile il salvataggio si annulla, invece di sovrascrivere la lista slot con una lista vuota.
- **Slot**: il GUID (SteamID64) identifica il giocatore. Due omonimi con account diversi non finiscono più sullo stesso slot; uno slot prenotato solo per nome viene adottato da chi si presenta con quel nome.
- **Processi esterni**: si termina solo il processo scelto, dopo aver verificato che il PID sia ancora `acServer.exe`.
- **Token d'invito**: se il generatore casuale di sistema fallisce compare un errore, invece di salvare un invito con token vuoto.
- **IPv6**: gli indirizzi sono racchiusi tra parentesi quadre negli URL dell'API.
- **Launcher**: il token viaggia nell'header `Authorization: Bearer`, non più nella query string o nel corpo JSON.
- **Ascolto API**: un indirizzo di ascolto non valido non ricade più su tutte le interfacce: l'API non parte e l'errore finisce nel log.

### Compatibilità

- I launcher della 1.0.0 e della 1.0.1 continuano a funzionare: il server accetta ancora il token nel parametro e nel corpo della richiesta.
- I link già distribuiti restano validi.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **`entry_list.ini`**: only a missing file counts as empty. If the file is locked or unreadable the save is aborted, instead of overwriting the slot list with an empty one.
- **Slots**: the GUID (SteamID64) identifies the player. Two people with the same name but different accounts no longer share a slot; a slot booked by name only is adopted by whoever shows up with that name.
- **External processes**: only the selected process is terminated, after checking the PID is still `acServer.exe`.
- **Invite token**: if the system random generator fails an error is shown, instead of saving an invite with an empty token.
- **IPv6**: addresses are wrapped in square brackets in API URLs.
- **Launcher**: the token travels in the `Authorization: Bearer` header, no longer in the query string or JSON body.
- **API binding**: an invalid listen address no longer falls back to all interfaces: the API does not start and the error is logged.

### Compatibility

- 1.0.0 and 1.0.1 launchers keep working: the server still accepts the token in the query string and request body.
- Already shared links stay valid.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
