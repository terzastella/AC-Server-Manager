# AC Server Control — v1.0.20

Aggiornamento delle dipendenze e della toolchain: nessun cambiamento funzionale.

## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,4 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,4 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **Dipendenze Rust aggiornate**: `base64` 0.23, `getrandom` 0.4, `windows-sys` 0.61, `if-addrs` 0.15, `junction` 2.1.
- **Frontend aggiornato**: `vite` 8, `@vitejs/plugin-react` 6, `typescript` 7 (con le dichiarazioni `vite-env.d.ts`).
- **GitHub Actions**: `actions/checkout` 7, `actions/setup-node` 7, `action-gh-release` 3, tutte pinnate per SHA.
- **CI e release su Node 22** (richiesto da Vite 8).
- Nessuna modifica a comportamento, formato dei file o interfaccia.

### Compatibilità

- Nessun cambiamento visibile e nessuna modifica al formato dei file.
- I launcher 1.0.2–1.0.19 sono compatibili.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.4 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.4 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **Rust dependencies updated**: `base64` 0.23, `getrandom` 0.4, `windows-sys` 0.61, `if-addrs` 0.15, `junction` 2.1.
- **Frontend updated**: `vite` 8, `@vitejs/plugin-react` 6, `typescript` 7 (with the `vite-env.d.ts` declarations).
- **GitHub Actions**: `actions/checkout` 7, `actions/setup-node` 7, `action-gh-release` 3, all pinned by SHA.
- **CI and release on Node 22** (required by Vite 8).
- No behaviour, file-format or interface change.

### Compatibility

- No visible change and no change to the file format.
- 1.0.2–1.0.19 launchers are compatible.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot

{{CHECKSUMS}}
