# AC Server Control — v1.0.19

Due rifiniture su affidabilità: temporanei senza collisioni e token mai vuoto.

## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,4 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,4 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **Scrittura atomica**: il nome del temporaneo include l'istante di scrittura, quindi un `.tmp` rimasto da un crash non blocca più il primo salvataggio se il sistema riassegna lo stesso PID.
- **Token d'invito**: un salvataggio delle impostazioni non può più azzerare il token; se non ne arriva uno viene tenuto quello in uso oppure generato uno nuovo.

### Compatibilità

- Nessun cambiamento visibile nell'interfaccia e nessuna modifica al formato dei file.
- I launcher 1.0.2–1.0.18 sono compatibili.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.4 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.4 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **Atomic write**: the temporary file name includes the write instant, so a `.tmp` left behind by a crash no longer blocks the first save when the system reuses the same PID.
- **Invite token**: saving settings can no longer blank the token; if none is provided the current one is kept, or a new one is generated.

### Compatibility

- No visible interface change and no change to the file format.
- 1.0.2–1.0.18 launchers are compatible.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
