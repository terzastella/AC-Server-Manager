# AC Server Control — v1.0.16

Il Launcher tratta `race.ini` con la stessa cura del Manager: niente sovrascritture a vuoto.

## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **`race.ini` nel Launcher**: un file illeggibile (permessi, contenuto non UTF-8) non viene più trattato come vuoto e sovrascritto. Il backup deve riuscire, altrimenti il join si ferma, e la scrittura è atomica come nel Manager.
- **SteamID64 obbligatorio**: se Steam non fornisce lo SteamID64 il launcher si ferma con un messaggio chiaro, invece di avviare il gioco con un GUID vuoto che non entrerebbe nello slot.
- **Profili**: una junction dentro `profiles/` non viene più adottata come profilo quando l'indice viene ricostruito.

### Compatibilità

- Nessun cambiamento visibile nell'interfaccia e nessuna modifica al formato dei file.
- I launcher 1.0.2–1.0.15 sono compatibili.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **`race.ini` in the Launcher**: an unreadable file (permissions, non-UTF-8 content) is no longer treated as empty and overwritten. The backup must succeed or the join stops, and the write is atomic like in the Manager.
- **SteamID64 required**: if Steam does not provide the SteamID64 the launcher stops with a clear message, instead of starting the game with an empty GUID that would not claim the slot.
- **Profiles**: a junction inside `profiles/` is no longer adopted as a profile when the index is rebuilt.

### Compatibility

- No visible interface change and no change to the file format.
- 1.0.2–1.0.15 launchers are compatible.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
