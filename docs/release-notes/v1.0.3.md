## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **Confronto del token a tempo costante**: il tempo di risposta non dipende da quanti caratteri combaciano.
- **Avviso sull'esposizione**: quando l'API ascolta su `0.0.0.0` la pagina Invito lo dice, così la scelta è consapevole. Con una VPN conviene selezionare l'indirizzo della VPN.
- **Porta API**: se la porta scelta è occupata si usa la successiva e il link d'invito punta a quella davvero aperta.
- **Impostazioni**: se `settings.json` non si riesce a scrivere il comando fallisce e l'errore arriva in interfaccia; prima il salvataggio sembrava riuscito. Scritture atomiche, serializzate, con file temporaneo univoco e verifica del contenuto.
- **File danneggiati**: un `settings.json` non valido o un `profiles/index.json` corrotto vengono conservati con un nome di recupero, non sovrascritti.
- **Percorsi dei contenuti**: identificativi con separatori, `..` o unità di disco vengono rifiutati prima di copiare.
- **Junction dei profili**: create con l'API di Windows, senza passare da `cmd.exe`.
- **API**: header malformati o duplicati, `Content-Length` non numerico e `Transfer-Encoding` vengono rifiutati. Le prenotazioni rispondono con 400 (dati non validi), 409 (nessuno slot) e 500 (errore interno) invece di 200.
- **Rate limiter**: gli IP inattivi vengono dimenticati e la mappa ha un tetto massimo.
- **Processi esterni**: il percorso deve essere assoluto e il file deve chiamarsi esattamente `acServer.exe`; se il percorso non è leggibile la terminazione viene rifiutata.

### Compatibilità

- Nessuna modifica ai link d'invito, al protocollo o ai file `.ini`.
- I launcher 1.0.0, 1.0.1 e 1.0.2 continuano a funzionare.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **Constant-time token comparison**: response time does not depend on how many characters match.
- **Exposure warning**: when the API listens on `0.0.0.0` the Invite page says so, making the choice explicit. With a VPN, pick the VPN address instead.
- **API port**: if the chosen port is busy the next free one is used, and the invite link points to the port actually open.
- **Settings**: if `settings.json` cannot be written the command fails and the error reaches the UI; previously the save looked successful. Atomic, serialized writes with a per-write temp file and content verification.
- **Damaged files**: an invalid `settings.json` or a corrupt `profiles/index.json` is kept under a recovery name, never overwritten.
- **Content paths**: identifiers containing separators, `..` or drive letters are rejected before copying.
- **Profile junctions**: created through the Windows API, without `cmd.exe`.
- **API**: malformed or duplicate headers, non-numeric `Content-Length` and `Transfer-Encoding` are rejected. Bookings answer with 400 (invalid data), 409 (no slot) and 500 (internal error) instead of 200.
- **Rate limiter**: idle IPs are forgotten and the map has a hard cap.
- **External processes**: the path must be absolute and the file name exactly `acServer.exe`; if the path cannot be read the termination is refused.

### Compatibility

- No changes to invite links, the protocol or `.ini` files.
- 1.0.0, 1.0.1 and 1.0.2 launchers keep working.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
