# AC Server Control — v1.0.5

Concorrenza sulla lista slot e sulle impostazioni: nessuna prenotazione persa.

## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **Prenotazioni, salvataggio manuale di slot e configurazione** condividono lo stesso lock: non si sovrascrivono più a vicenda.
- **Lista obsoleta**: se un amico prenota mentre hai la pagina slot aperta, il salvataggio viene rifiutato e ti chiede di ricaricare, invece di cancellare la prenotazione.
- **`settings.json`**: se il file è illeggibile o non valido il salvataggio si interrompe e il contenuto resta intatto.
- **Lock Manager/Launcher**: ogni processo rimuove solo il proprio lock, mai quello subentrato dopo un timeout.
- **API**: il tetto di 32 connessioni vale prima della creazione del thread.
- **Profili**: se l'indice è corrotto, le cartelle dei profili vengono reimportate automaticamente.
- **Release CI**: prima di compilare, il workflow esegue i18n, TypeScript, `cargo fmt`, Clippy e i test.

### Compatibilità

- Nessuna modifica a link d'invito, protocollo o file `.ini`.
- I launcher 1.0.0–1.0.4 continuano a funzionare.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **Bookings, manual slot saving and configuration** share the same lock: they no longer overwrite each other.
- **Stale list**: if a friend books while your slot page is open, saving is refused and asks you to reload, instead of deleting the booking.
- **`settings.json`**: if the file is unreadable or invalid the save is aborted and the content is left untouched.
- **Manager/Launcher lock**: each process removes only its own lock, never one taken over after a timeout.
- **API**: the 32-connection cap applies before the thread is created.
- **Profiles**: when the index is corrupt, profile folders are re-imported automatically.
- **Release CI**: the tag workflow runs i18n, TypeScript, `cargo fmt`, Clippy and tests before building.

### Compatibility

- No changes to invite links, the protocol or `.ini` files.
- 1.0.0–1.0.4 launchers keep working.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
