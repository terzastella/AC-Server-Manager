# AC Server Control — v1.0.15

Dettagli dell'API e della CI: schema Bearer case-insensitive, timeout verificati, avviso sul token mancante.

## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **Bearer case-insensitive**: `Authorization: BEARER …` e ogni altra combinazione di maiuscole vengono accettate, come previsto dallo standard HTTP.
- **Timeout obbligatori**: se il socket non accetta i timeout di lettura/scrittura la connessione viene chiusa subito, invece di essere servita senza protezione anti-slowloris.
- **Token d'invito assente**: la pagina Invito avvisa in modo esplicito se il token è vuoto, invece di lasciare gli inviti inutilizzabili senza spiegazione.
- **Controllo versioni più completo**: la CI confronta anche la prima voce del CHANGELOG e, quando gira su un tag, verifica che il tag coincida con la versione dei manifest.

### Compatibilità

- Nessun cambiamento visibile nell'interfaccia e nessuna modifica al formato dei file.
- I launcher 1.0.2–1.0.14 sono compatibili.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **Case-insensitive Bearer**: `Authorization: BEARER …` and any other capitalisation are accepted, as the HTTP standard requires.
- **Mandatory timeouts**: if the socket refuses the read/write timeouts the connection is closed immediately, instead of being served without slowloris protection.
- **Missing invite token**: the Invite page now warns explicitly when the token is empty, instead of leaving invites unusable with no explanation.
- **Better version check**: CI also compares the first CHANGELOG entry and, when running on a tag, verifies that the tag matches the manifest version.

### Compatibility

- No visible interface change and no change to the file format.
- 1.0.2–1.0.14 launchers are compatible.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
