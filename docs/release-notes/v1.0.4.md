# AC Server Control — v1.0.4

Correzione di concorrenza: Manager e Launcher non si cancellano più le impostazioni a vicenda.

## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **Manager e Launcher insieme**: i due programmi condividono `settings.json` e prima l'ultimo che salvava cancellava i campi dell'altro (per esempio il nome del pilota scelto nel launcher). Ora ogni processo rilegge il file e scrive solo i campi di sua competenza, con un lock tra processi.
- Include tutte le correzioni della 1.0.3: porta API effettiva negli inviti, indice profili conservato se corrotto, validazione dei percorsi dei contenuti, junction senza `cmd.exe`, recupero di `settings.json` danneggiato, parser HTTP rigoroso, codici 400/409/500, rate limiter con tetto, confronto del token con `subtle`.

### Compatibilità

- Nessuna modifica a link d'invito, protocollo o file `.ini`.
- I launcher 1.0.0–1.0.3 continuano a funzionare.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **Manager and Launcher together**: both share `settings.json` and previously the last one to save wiped the other's fields (for example the driver name picked in the launcher). Now each process re-reads the file and writes only its own fields, under a cross-process lock.
- Includes every 1.0.3 fix: effective API port in invites, profile index preserved when corrupt, content path validation, junctions without `cmd.exe`, recovery of a damaged `settings.json`, strict HTTP parser, 400/409/500 status codes, capped rate limiter, token comparison via `subtle`.

### Compatibility

- No changes to invite links, the protocol or `.ini` files.
- 1.0.0–1.0.3 launchers keep working.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
