# AC Server Control — v1.0.18

Hardening dei percorsi e delle scritture: profili fail-closed, backup verificati, un solo writer atomico.

## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,4 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,4 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **Profili**: adozione solo se la cartella è reale, `cfg/` è una cartella reale e `content/` è assente, reale o una junction verso la cartella condivisa. Un `cfg/` junction non passa più anche quando `content` esiste; errori di permessi o di verifica rifiutano il profilo invece di accettarlo.
- **Backup configurazioni**: i file vengono controllati tutti prima di copiarne uno; un link o un reparse point ferma il backup e la cartella creata a metà viene rimossa.
- **`assists.ini`**: un file illeggibile non viene più sovrascritto come se fosse vuoto, il backup è obbligatorio e la scrittura è atomica.
- **`race.ini`**: un link o un reparse point viene rifiutato; i backup hanno un nome datato e si conservano le ultime dieci copie.
- **Scrittura atomica unica** per configurazioni, `race.ini`, `assists.ini`, `settings.json` e `profiles/index.json`: temporaneo esclusivo, sincronizzazione, rilettura, rename, pulizia in caso di errore.

### Compatibilità

- Nessun cambiamento visibile nell'interfaccia; i backup di `race.ini` cambiano nome (`race.ini.<data>.bak`).
- I launcher 1.0.2–1.0.17 sono compatibili.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.4 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.4 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **Profiles**: a profile is adopted only if its folder is real, `cfg/` is a real folder and `content/` is missing, real, or a junction to the shared content folder. A junction `cfg/` no longer passes just because `content` exists; permission or verification errors reject the profile instead of accepting it.
- **Configuration backups**: every file is checked before the first copy; a link or reparse point stops the backup and the half-created folder is removed.
- **`assists.ini`**: an unreadable file is no longer overwritten as if it were empty, the backup is mandatory and the write is atomic.
- **`race.ini`**: a link or reparse point is refused; backups get a dated name and the last ten are kept.
- **Single atomic write** for configuration, `race.ini`, `assists.ini`, `settings.json` and `profiles/index.json`: exclusive temporary, sync, read-back, rename, cleanup on error.

### Compatibility

- No visible interface change; `race.ini` backups change name (`race.ini.<date>.bak`).
- 1.0.2–1.0.17 launchers are compatible.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
