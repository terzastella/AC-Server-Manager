## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **Token d'invito** generato con un CSPRNG di sistema (32 byte, base64url) invece che da tempo e PID.
- **API di prenotazione**: token accettato nell'header `Authorization: Bearer`, scadenza opzionale dell'invito, scelta dell'interfaccia di rete su cui ascoltare, timeout di lettura/scrittura, limite sugli header e sulle connessioni contemporanee.
- **`entry_list.ini`**: il salvataggio aggiorna solo i campi noti e preserva commenti, ordine e chiavi sconosciute.
- **Backup**: se il backup fallisce il salvataggio viene annullato; le scritture sono atomiche (file temporaneo, verifica, sostituzione).
- **Prenotazioni**: la livrea deve appartenere all'auto scelta e lo SteamID64 deve essere un account valido; lo stesso SteamID riusa il suo slot.
- **CSP di Tauri** attiva: niente script, frame o origini esterne.
- **Processi esterni**: prima di fermarli l'app mostra PID e percorso di ognuno.
- **CI**: aggiunto `cargo clippy -D warnings`.

### Compatibilità

- I launcher della 1.0.0 continuano a funzionare: il token è ancora accettato nel parametro e nel corpo della richiesta.
- I link già distribuiti restano validi: la scadenza è disattivata per impostazione predefinita.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **Invite token** generated with a system CSPRNG (32 bytes, base64url) instead of time and PID.
- **Booking API**: token accepted in the `Authorization: Bearer` header, optional invite expiry, selectable listening interface, read/write timeouts, limits on headers and concurrent connections.
- **`entry_list.ini`**: saving updates only known fields and preserves comments, order and unknown keys.
- **Backups**: if the backup fails the save is aborted; writes are atomic (temp file, verify, replace).
- **Bookings**: the skin must belong to the chosen car and the SteamID64 must be a valid account; the same SteamID reuses its slot.
- **Tauri CSP** enabled: no external scripts, frames or origins.
- **External processes**: the app shows PID and path before stopping them.
- **CI**: `cargo clippy -D warnings` added.

### Compatibility

- 1.0.0 launchers keep working: the token is still accepted in the query string and request body.
- Already shared links stay valid: expiry is disabled by default.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
