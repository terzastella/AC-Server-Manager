## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **Salvataggio degli slot legato alla versione letta**: se nel frattempo è arrivata una prenotazione, il salvataggio viene rifiutato anche quando la pagina ha riletto gli slot in background. Niente più liste vecchie che cancellano prenotazioni.
- **Pulsante Salva disattivato** finché ci sono prenotazioni in attesa: prima devi "Scarta e ricarica".
- **Backup**: nomi con millisecondi e suffisso progressivo, quindi due backup ravvicinati restano separati.
- **`welcome.txt`** usa lo stesso lock dei preset: lo snapshot dei tre file è coerente.
- **Processi esterni**: verifica e terminazione sullo stesso handle Windows, senza finestra di riuso del PID.

### Compatibilità

- Nessuna modifica a link d'invito, protocollo o file `.ini`.
- I launcher 1.0.0–1.0.6 continuano a funzionare.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **Saving slots is tied to the version you loaded**: if a booking arrived in the meantime, the save is refused even when the page re-read the slots in the background. No more stale lists wiping bookings.
- **Save button disabled** while bookings are pending: you must "Discard and reload" first.
- **Backups**: names include milliseconds and a progressive suffix, so two close backups stay separate.
- **`welcome.txt`** uses the same lock as presets: the three-file snapshot is consistent.
- **External processes**: verification and termination on the same Windows handle, no PID-reuse window.

### Compatibility

- No changes to invite links, the protocol or `.ini` files.
- 1.0.0–1.0.6 launchers keep working.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
