## 🇮🇹 Italiano

### Cosa scaricare

| File | A cosa serve | Dimensione |
|---|---|---|
| **ACServerControl.exe** | Il pannello: avvio/stop, configurazione, slot, contenuti, inviti, profili, preset, log | 9,3 MB |
| **ACLauncher.exe** | Il launcher per gli amici: link d'invito, scelta auto e livrea, prenotazione slot | 9,3 MB |
| **SHA256SUMS.txt** | Checksum dei due eseguibili | < 1 KB |

### Cosa cambia

- **Caricamento dei preset**: il percorso della cartella veniva costruito con il nome ricevuto dall'interfaccia senza controllarlo, quindi `..`, separatori o percorsi assoluti potevano puntare fuori da `presets/`. Ora il percorso viene canonizzato e deve restare dentro `presets/`, con lo stesso criterio già usato in salvataggio.
- Nessun cambiamento visibile nell'interfaccia e nessuna modifica a inviti, protocollo o file `.ini`.

### Compatibilità

- Aggiornamento consigliato ma non obbligatorio: la 1.0.9 si comporta allo stesso modo per l'uso normale.
- I preset esistenti continuano a funzionare; i launcher 1.0.2–1.0.9 sono compatibili.
- Sostituisci entrambi gli `.exe`: manager e launcher devono essere della stessa versione.

### Requisiti

- Windows 10/11 x64 con **WebView2 Runtime** (già presente su Windows 11)
- **Assetto Corsa** con i file del server dedicato (`acServer.exe`, `content/`)
- **Steam aperto**: il launcher legge lo SteamID64 per occupare lo slot

## 🇬🇧 English

### What to download

| File | Purpose | Size |
|---|---|---|
| **ACServerControl.exe** | The manager: start/stop, configuration, slots, content, invites, profiles, presets, logs | 9.3 MB |
| **ACLauncher.exe** | The launcher for friends: invite link, car and skin picker, slot booking | 9.3 MB |
| **SHA256SUMS.txt** | Checksums of both executables | < 1 KB |

### What changed

- **Loading presets**: the folder path was built from the name received from the interface without checking it, so `..`, separators or absolute paths could point outside `presets/`. The path is now canonicalized and must stay inside `presets/`, the same rule the save path already used.
- No visible interface change and no change to invites, the protocol or `.ini` files.

### Compatibility

- Recommended but not required: 1.0.9 behaves the same for normal use.
- Existing presets keep working; 1.0.2–1.0.9 launchers are compatible.
- Replace both `.exe` files: manager and launcher must be the same version.

### Requirements

- Windows 10/11 x64 with **WebView2 Runtime** (bundled with Windows 11)
- **Assetto Corsa** with the dedicated server files (`acServer.exe`, `content/`)
- **Steam running**: the launcher reads the SteamID64 to claim the slot
